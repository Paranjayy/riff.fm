# riff.fm 🎸

A premium, high-performance Spotify taste analysis and comparison platform.

## Features
- **Taste Match**: Compare your musical soul with friends.
- **Deep Analytics**: Professional-grade stats for your top artists, tracks, and listening habits.
- **Glassmorphic UI**: A stunning, modern interface built with Framer Motion and Tailwind CSS.
- **CI/CD Ready**: Integrated with GitHub Actions and Vercel.

## Setup
1. `npm install`
2. `npm run dev`

## Deployment
Pushing to the `main` branch automatically triggers the build and deploy pipeline.
